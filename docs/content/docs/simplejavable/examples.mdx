To learn how to use SimpleJavaBLE, please refer to the [examples](https://github.com/simpleble/simpleble/tree/main/examples/simplejavable) provided in the repository.

The example project includes:

- **ScanExample**: Scan for nearby peripherals and print advertisement details.
- **ConnectExample**: Scan, choose a connectable peripheral, connect, and list services and characteristics.
- **NotifyExample**: Connect to a peripheral, choose a characteristic, subscribe to notifications, then unsubscribe.
- **PeripheralExample**: Advertise a local GATT service whose characteristic echoes writes to subscribed clients.
- **DonglExample**: Select a [Dongl](../dongl) adapter, scan, and connect with pairing callbacks registered.

For setup details, see [Usage](./usage), [Installation](../installation), and [Quickstart](../quickstart).
