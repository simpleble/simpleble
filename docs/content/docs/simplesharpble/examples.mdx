The [examples](https://github.com/simpleble/simpleble/tree/main/examples/simplesharpble)
follow the C++ examples, with one file-based C# app per use case.

The [Android scan app](https://github.com/simpleble/simpleble/tree/main/examples/simplesharpble-android)
demonstrates Android initialization, runtime permissions, and background scanning.

## Run an example

Each example is a single `.cs` file that .NET 10 runs directly. To run one
against the published package, copy it and replace its first line,
`#:project ../../simplesharpble`, with a package reference:

```csharp
#:package SimpleSharpBLE@1.3.*
```

Then run it with `dotnet run scan.cs`.

To run the examples against the repository sources instead, build the native
libraries and pass their directory to `dotnet run`:

```sh
cmake -S simplecble -B build_simplecble -DBUILD_SHARED_LIBS=ON -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_LIBDIR=lib
cmake --build build_simplecble --config Release --parallel
cmake --install build_simplecble --config Release --prefix "$PWD/build_simplecble/install"
dotnet run examples/simplesharpble/scan.cs -p:NativeLibraryDirectory="$PWD/build_simplecble/install/lib"
```

On Windows, the DLLs are in `build_simplecble/install/bin`.

## Central

| Example | Demonstrates |
| --- | --- |
| [list_adapters](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/list_adapters.cs) | Backends and their adapters, plus the consolidated adapter list. |
| [list_paired](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/list_paired.cs) | Paired devices for each adapter. |
| [power_cycle](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/power_cycle.cs) | Adapter power control and events. |
| [scan](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/scan.cs) | Discovery events, signal strength, service data, and manufacturer data. |
| [connect](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/connect.cs) | Device selection, connection, MTU, services, characteristics, and descriptors. |
| [multiconnect](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/multiconnect.cs) | Five connect/disconnect cycles and connection events. |
| [read](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/read.cs) | Characteristic selection and repeated reads. |
| [write](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/write.cs) | Acknowledged or unacknowledged writes of hex bytes. |
| [notify](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/notify.cs) | Notifications and unsubscription. |
| [indicate](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/indicate.cs) | Indications and unsubscription. |
| [notify_multi](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/notify_multi.cs) | Notifications from two devices and staggered disconnection. |

## Peripheral

[peripheral](https://github.com/simpleble/simpleble/blob/main/examples/simplesharpble/peripheral.cs)
advertises a custom service, accepts reads and writes, echoes written values to
subscribers, and reports client and subscription events. Press Ctrl+C to stop.
