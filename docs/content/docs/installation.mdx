SimpleBLE is a family of libraries. Start by choosing the binding that matches your application, then install the platform dependencies that binding needs.

## Choose a binding

| Binding | Language | Status | Best fit | Install path |
| --- | --- | --- | --- | --- |
| [SimpleBLE](./simpleble/usage) | C++ | Production-ready | Native desktop, mobile native code, shared libraries | CMake from source |
| [SimpleCBLE](./simplecble/usage) | C | Production-ready | C applications, FFI, language bridges | CMake from source |
| [SimpleSharpBLE](./simplesharpble/usage) | C# / .NET | Production-ready | Desktop, mobile, and MAUI apps; test and industrial tooling | [NuGet](https://www.nuget.org/packages/SimpleSharpBLE/) |
| [SimplePyBLE](./simplepyble/usage) | Python | Production-ready | Scripts, tools, data pipelines, tests | PyPI or local source |
| [SimpleJavaBLE](./simplejavable/usage) | Java | Production-ready | JVM desktop apps and integrations | Maven Central or local source |
| [SimpleGoBLE](./simplegoble/usage) | Go | Production-ready | Desktop apps, tools, and services | Go modules |
| [SimpleRsBLE](./simplersble/usage) | Rust | Production-ready | Rust applications and async workflows | crates.io or local path |
| [SimpleJSBLE](./simplejsble/usage) | JavaScript / TypeScript | Production-ready | Node.js and Electron apps | npm |
| [SimpleRnBLE](./simplernble/usage) | JavaScript / TypeScript | Production-ready | React Native apps on iOS and Android | npm |

## Platform prerequisites

| Platform | Required setup |
| --- | --- |
| Linux | BlueZ, DBus development headers, and permission to access the system Bluetooth stack. On Ubuntu, install `libdbus-1-dev`. |
| Windows | Windows 10 or newer, Windows SDK `10.0.22621.0` or newer, and a C++20-capable MSVC toolchain such as Visual Studio 2019 16.11 or newer. |
| macOS | macOS 15.0 or newer and Xcode Command Line Tools. Packaged apps need Bluetooth usage strings in `Info.plist`. |
| iOS | iOS 15.8 or newer and the normal CoreBluetooth permission flow. |
| Android | API 31 or newer, Android Studio, Android NDK, manifest permissions, and runtime Bluetooth permission requests. |

See [Bluetooth Permissions](./fundamentals/permissions) for the OS-specific permission details that are easy to miss on first adoption.

## Install commands

<Tabs items={["C++", "C", "C#", "Python", "Java", "Go", "Rust", "Node.js", "React Native", "Kotlin Multiplatform", "Swift", "Dart", "Flutter", "Delphi", "Android", "Unity", "SimpleAIBLE"]}>
<Tab value="C++">

Build and install the C++ library from source:

```bash
git clone https://github.com/simpleble/simpleble.git
cd simpleble

cmake -S simpleble -B build_simpleble
cmake --build build_simpleble -j
cmake --install build_simpleble --prefix "$PWD/install_simpleble"
```

Consume the installed package from your own CMake project:

```cmake
find_package(simpleble REQUIRED CONFIG)
target_link_libraries(your_app PRIVATE simpleble::simpleble)
```

For a local vendored build, add the library directly:

```cmake
add_subdirectory(path/to/simpleble/simpleble ${CMAKE_BINARY_DIR}/simpleble)
target_link_libraries(your_app PRIVATE simpleble::simpleble)
```

</Tab>
<Tab value="C">

Build and install the C wrapper from source:

```bash
git clone https://github.com/simpleble/simpleble.git
cd simpleble

cmake -S simplecble -B build_simplecble
cmake --build build_simplecble -j
cmake --install build_simplecble --prefix "$PWD/install_simplecble"
```

Consume the installed package from CMake:

```cmake
find_package(simplecble REQUIRED CONFIG)
target_link_libraries(your_app PRIVATE simplecble::simplecble)
```

If you are compiling manually, include `simplecble` headers and link both `simplecble` and the platform Bluetooth dependencies.

</Tab>
<Tab value="C#">

Install SimpleSharpBLE from [NuGet](https://www.nuget.org/packages/SimpleSharpBLE/):

```sh
dotnet add package SimpleSharpBLE
```

Requires .NET 10. See [SimpleSharpBLE Usage](./simplesharpble/usage) for platform requirements
and a first scan example.

</Tab>
<Tab value="Python">

Install the Python binding from PyPI:

```bash
pip install simplepyble
```

Linux users also need DBus headers:

```bash
sudo apt-get install libdbus-1-dev
```

Install from a local checkout when developing SimplePyBLE itself:

```bash
git clone https://github.com/simpleble/simpleble.git
cd simpleble
pip install .
```

</Tab>
<Tab value="Java">

Add SimpleJavaBLE to your Gradle dependencies:

```kotlin
dependencies {
    implementation("org.simpleble:simplejavable:<version>")
}
```

The Maven artifact bundles the supported Windows, macOS, and Linux native libraries. See [SimpleJavaBLE Usage](./simplejavable/usage) for source builds and native library loading options.

</Tab>
<Tab value="Go">

Install the Go binding with Go 1.25 or newer:

```sh
go get github.com/simpleble/simplegoble
go build ./...
```

See [SimpleGoBLE Usage](./simplegoble/usage) for platform requirements and
client examples.

</Tab>
<Tab value="Rust">

Add the Rust crate:

```bash
cargo add simplersble
```

Linux users need DBus headers before building:

```bash
sudo apt-get install libdbus-1-dev
```

If you want to use a local checkout while developing:

```toml
[dependencies]
simplersble = { path = "path/to/simpleble" }
```

</Tab>
<Tab value="Node.js">

Install the Node.js package with Node.js 22 or newer:

```sh
npm install simplejsble
```

The package includes the native addon for Windows, macOS, and Linux on x64 and
arm64, so nothing is compiled during installation. See
[SimpleJSBLE Usage](./simplejsble/usage) for Electron and platform notes.

</Tab>
<Tab value="React Native">

Install the React Native package and Nitro Modules, which it is built on:

```sh
npm install simplernble react-native-nitro-modules
cd ios && pod install
```

The package includes SimpleBLE prebuilt for iOS, and compiles it with the NDK
in your app's Android build. Apps target iOS 15.8 and Android API 31 or newer,
declare Bluetooth usage in `Info.plist`, and request the Android permissions at
runtime; see
[SimpleRnBLE Usage](./simplernble/usage) for permissions and Expo.

</Tab>
<Tab value="Kotlin Multiplatform">

Add SimpleKtBLE to the shared module of your project, with Kotlin 2.3 or newer:

```kotlin
kotlin {
    sourceSets {
        commonMain.dependencies {
            implementation("org.simpleble:simplektble:<version>")
        }
    }
}
```

Each target's artifact includes the native SimpleBLE library it needs, for Android, iOS, macOS, Windows, and
Linux, so nothing is compiled during your build. See [SimpleKtBLE Usage](./simplektble/usage) for permissions
and supported targets.

</Tab>
<Tab value="Swift">

Add SimpleSwiftBLE with Swift Package Manager, with Swift 6.0 (Xcode 16) or newer. In Xcode, choose
**File > Add Package Dependencies**, enter `https://github.com/simpleble/simpleswiftble`, and add the `SimpleSwiftBLE`
library to your target. In a `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/simpleble/simpleswiftble", from: "<version>")
],
targets: [
    .target(name: "MyApp", dependencies: [.product(name: "SimpleSwiftBLE", package: "simpleswiftble")])
]
```

The package includes SimpleBLE prebuilt for iOS, macOS, and Mac Catalyst, so only the Swift layer compiles with your
app. See [SimpleSwiftBLE Usage](./simpleswiftble/usage) for permissions and supported platforms.

</Tab>
<Tab value="Dart">

Add SimpleDartBLE to your Dart program, with Dart 3.10 or newer:

```sh
dart pub add simpledartble
```

The package includes the native SimpleBLE library for Windows, macOS, and Linux, so nothing is compiled during your
build. See [SimpleDartBLE Usage](./simpledartble/usage) for permissions.

</Tab>
<Tab value="Flutter">

Add SimpleFltBLE to your Flutter app, with Flutter 3.38 or newer:

```sh
flutter pub add simplefltble
```

The package includes the native SimpleBLE library for Android, iOS, macOS, Windows, and Linux, so nothing is compiled
during your build. See [SimpleFltBLE Usage](./simplefltble/usage) for app setup and permissions.

</Tab>
<Tab value="Delphi">

Install SimpleDelphiBLE with [Boss](https://github.com/HashLoad/boss), for Delphi 11 or newer or Free Pascal 3.2.2
or newer:

```sh
boss install github.com/simpleble/simpledelphible
```

Or download a [release](https://github.com/simpleble/simpledelphible/releases) and add its `source` folder to your
search path. Both include the native SimpleBLE libraries for Windows, macOS, and Linux; deploy the ones for your target
with your application. See [SimpleDelphiBLE Usage](./simpledelphible/usage) for deployment and Free Pascal settings.

</Tab>
<Tab value="Android">

Add SimpleDroidBLE to your app module:

```kotlin
dependencies {
    implementation("org.simpleble:simpledroidble:<version>")
}
```

For a local checkout, include the library before `include(":app")`:

```kotlin
includeBuild("path/to/simpleble/simpledroidble") {
    dependencySubstitution {
        substitute(module("org.simpleble:simpledroidble")).using(project(":simpledroidble"))
    }
}

include(":app")
```

The app must also declare and request Bluetooth permissions at runtime.

</Tab>
<Tab value="Unity">

In Unity's Package Manager, select **My Assets**, find **SimpleBLE for Unity**,
then download and import it. For a supplied `.unitypackage`, use **Assets > Import
Package > Custom Package**. Use Unity 6.3 LTS or 6.6.

See [SimpleBLE for Unity Installation](./simpleunityble/installation) for assembly
references and [Platform notes](./simpleunityble/platform_notes) for Android settings.

</Tab>
<Tab value="SimpleAIBLE">

Install with `uv`:

```bash
uv tool install simpleaible
```

Or with pip:

```bash
pip install simpleaible
```

Then run the MCP server:

```bash
simpleaible
```

See [MCP Server](./simpleaible/mcp) and [HTTP Server](./simpleaible/http) for agent and HTTP workflows.

</Tab>

## Verify the install

The fastest smoke test is to scan for nearby devices:

- C++, C, Python, Java, Rust, Node.js, React Native, Kotlin Multiplatform, Swift, Dart, Delphi, Android, Unreal, and Unity users can start with [Quickstart](./quickstart).
- C# users can start with the scan example in [SimpleSharpBLE Usage](./simplesharpble/usage).
- CMake users can build the repository examples from [SimpleBLE Examples](./simpleble/examples) or [SimpleCBLE Examples](./simplecble/examples).
- Python users can run the examples under `examples/simplepyble`.
- Rust users can run the examples under `examples/simplersble`.
- Android users can run the example app under `examples/simpleble-android`.
