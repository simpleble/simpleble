SimpleBLE is the cross-platform Bluetooth Low Energy stack for Windows, macOS, Linux, iOS, and Android. Use it from C++, C, C#, Python, Java, Kotlin, Swift, Dart, Delphi, Go, Rust, JavaScript, React Native, or Flutter, with a dedicated API for Unreal Engine.

> **New in v1.2**
>
> Host your own BLE peripherals on Windows, macOS, Linux, and Android with the new local peripheral-mode API, and use SimpleBLE from C# with **SimpleSharpBLE** on NuGet. The C API has been reworked; see the [migration guide](./simplecble/migration).

### Why SimpleBLE

* **One cross-platform API:** Keep application-facing BLE logic consistent across desktop and mobile.
* **Native underneath:** Use WinRT, CoreBluetooth, BlueZ, and Android Bluetooth through one maintained stack.
* **Built for real products:** Central- and peripheral-role support across all supported platforms.
* **Commercially supported:** Ship proprietary applications with licensing and direct technical support available.

### Language Bindings & Plugins

* **C++ (SimpleBLE):** Core implementation with full platform support.
* **C (SimpleCBLE):** C-wrapped version of the library.
* **C# (SimpleSharpBLE):** .NET bindings available from [NuGet](https://www.nuget.org/packages/SimpleSharpBLE/).
* **Python (SimplePyBLE):** Python bindings available from [PyPI](https://pypi.org/project/simplepyble/).
* **Java (SimpleJavaBLE):** Java bindings available from Maven Central with bundled desktop native libraries.
* **Go (SimpleGoBLE):** Go bindings without cgo, available as a [Go module](https://pkg.go.dev/github.com/simpleble/simplegoble).
* **Rust (SimpleRsBLE):** Rust bindings available from [crates.io](https://crates.io/crates/simplersble).
* **JavaScript (SimpleJSBLE):** Node.js and Electron bindings with TypeScript types, available from [npm](https://www.npmjs.com/package/simplejsble).
* **React Native (SimpleRnBLE):** iOS and Android bindings for React Native with TypeScript types, available from [npm](https://www.npmjs.com/package/simplernble).
* **Kotlin Multiplatform (SimpleKtBLE):** Kotlin Multiplatform bindings for Android, iOS, macOS, Windows, and Linux, available from Maven Central.
* **Swift (SimpleSwiftBLE):** Swift bindings with async/await for iOS, iPadOS, macOS, and Mac Catalyst, available with Swift Package Manager.
* **Dart (SimpleDartBLE):** Dart bindings for Windows, macOS, and Linux, available from [pub.dev](https://pub.dev/packages/simpledartble).
* **Flutter (SimpleFltBLE):** Flutter bindings for Android, iOS, macOS, Windows, and Linux, with SimpleDartBLE's API, available from [pub.dev](https://pub.dev/packages/simplefltble).
* **Delphi and Free Pascal (SimpleDelphiBLE):** Bindings for Delphi and Lazarus on Windows, macOS, and Linux, with events on the main thread of VCL, FMX, and LCL applications.
* **Android (SimpleDroidBLE):** Kotlin bindings for Android apps, available from Maven Central.
* **Unreal Engine (SimpleBLE for Unreal):** Unreal Engine plugin with Blueprint and C++ APIs.
* **Unity (SimpleBLE for Unity):** C# plugin for Windows and Android with IL2CPP support.

SimplePyBLE has surpassed 3.5 million downloads on PyPI.

### Getting Started

New to SimpleBLE or Bluetooth LE? Start with the shortest path that matches where you are:

* **Need to install a binding?** Use the [Installation](./installation) guide to choose the right package or source build path for C++, C, C#, Python, Java, Go, Rust, JavaScript, React Native, Kotlin Multiplatform, Swift, Dart and Flutter, Delphi, Android, Unreal Engine, and agent tooling.
* **Need a first working program?** Use the [Quickstart](./quickstart) to scan for nearby BLE devices with copy/paste snippets for each supported binding.
* **Need to build a real workflow?** Use the [Recipes](./recipes/scan) for scanning, connecting, and GATT operations like read, write, and notify.
* **New to BLE concepts?** Read [Fundamentals](./fundamentals) for Bluetooth LE basics, permissions, concurrency, and CMake setup.
