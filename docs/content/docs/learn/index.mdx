Learn Bluetooth Low Energy by running it. This free course starts with your first scan and ends with a connection that streams data. Every lesson runs on your own computer, in your language, with nothing to buy.

## How each lesson works

Each lesson teaches one idea and has you run it:

- **Concept.** A short explanation and one diagram.
- **Code.** A complete program in C++, C, Python, Java, Rust, Node.js, React Native, Kotlin Multiplatform, Swift, Dart, Delphi or Android. Pick your language once and every lesson opens in it.
- **What you should see.** The output that tells you it worked.
- **Exercise.** One change to make on your own.
- **Troubleshooting.** The fixes for the problems learners hit most often.
- **Tool.** A free SimpleBLE browser tool for the lesson's topic.

## What you need

- **A computer with Bluetooth.** Windows, macOS or Linux.
- **SimpleBLE for your language.** [Installation](/installation) lists the package for each language. For Python, run `pip install simplepyble`.
- **A device to talk to.** A phone with [nRF Connect for Mobile](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-mobile), a free app for Android and iOS, or a second computer running these lessons.

A computer without Bluetooth uses an nRF52840 USB dongle with the [free Dongl firmware](https://simpleble.org/dongl/nrf52840). The dongle appears as a Bluetooth adapter next to the computer's own.

## Go deeper

The [Fundamentals](/fundamentals) pages are the reference for each topic, and the [Recipes](/recipes/scan) show the patterns for production code. The free [SimpleBLE tools](https://simpleble.org/tools) decode advertisements, look up UUIDs, validate connection parameters and more, in the browser.

SimpleBLE is a source-available Bluetooth Low Energy library for Windows, macOS, Linux, iOS and Android. The course uses it so the same lesson runs on every operating system and in every language.
