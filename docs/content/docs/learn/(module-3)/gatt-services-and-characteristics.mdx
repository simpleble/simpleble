Once your program is connected, it reaches the device's data through GATT. In this lesson you learn how GATT arranges that data into services, characteristics and descriptors. Then your program connects to the course peripheral and prints every service, characteristic and descriptor it offers.

## The attribute table

GATT, the Generic Attribute Profile, keeps a device's data in a table of attributes. Each attribute has a handle, a type and a value. The handle is the attribute's number in the table. The type is a UUID that says what the attribute is. The value holds its data.

## Services, characteristics and descriptors

A service groups the characteristics of one feature. The course service groups Message and Counter, and a Battery Service groups what a device reports about its battery.

A characteristic is a declaration, which holds its properties and its UUID, followed by its value. The properties say what a central may do with the value:

- **Read.** The central asks for the current value.
- **Write.** The central sends a new value, and the peripheral confirms it.
- **Write without response.** The central sends a new value, and no confirmation follows.
- **Notify.** The peripheral sends each new value to the centrals that subscribed.
- **Indicate.** The peripheral sends each new value to the centrals that subscribed, and each central confirms it.

Descriptors follow the value and describe it. The Client Characteristic Configuration descriptor (CCCD, `0x2902`) holds a central's subscription to notifications or indications. The Characteristic User Description (`0x2901`) holds a name people can read.

Standard services and characteristics have 16-bit UUIDs from the Bluetooth SIG, such as `0x180A` for Device Information and `0x2A19` for Battery Level. A device's own services and characteristics use random 128-bit UUIDs, as the course peripheral does. The [GATT UUID Lookup](https://simpleble.org/tools/gatt-uuid-lookup) names the standard ones.

## GATT in SimpleBLE

SimpleBLE hides handles. After `connect()`, `services()` gives you the services, each with its characteristics, and each characteristic with its descriptors, all identified by UUID. Each characteristic also reports its properties. In SimpleBLE, a write is a write request, and a write without response is a write command.

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
#include <simpleble/SimpleBLE.h>

const std::string SERVICE = "76a60001-a8e9-4660-bc7b-ed8d93a6849e";

bool advertises_service(SimpleBLE::Peripheral& device) {
    for (auto& service : device.services()) {
        if (service.uuid() == SERVICE) return true;
    }
    return false;
}

std::string properties(SimpleBLE::Characteristic& characteristic) {
    std::vector<std::string> names;
    if (characteristic.can_read()) names.push_back("read");
    if (characteristic.can_write_request()) names.push_back("write");
    if (characteristic.can_write_command()) names.push_back("write without response");
    if (characteristic.can_notify()) names.push_back("notify");
    if (characteristic.can_indicate()) names.push_back("indicate");

    std::string text;
    for (auto& name : names) {
        text += (text.empty() ? "" : ", ") + name;
    }
    return text;
}

int main() {
    auto adapter = SimpleBLE::Adapter::get_adapters().at(0);
    adapter.scan_for(5000);

    auto results = adapter.scan_get_results();
    auto found = std::find_if(results.begin(), results.end(), advertises_service);
    if (found == results.end()) {
        std::cout << "Course peripheral not found. Start it and run this program again." << std::endl;
        return 1;
    }
    auto peripheral = *found;

    std::cout << "Connecting to " << peripheral.address() << std::endl;
    peripheral.connect();
    std::cout << "Connected" << std::endl;

    for (auto& service : peripheral.services()) {
        std::cout << "Service " << service.uuid() << std::endl;
        for (auto& characteristic : service.characteristics()) {
            std::cout << "  Characteristic " << characteristic.uuid() << ": " << properties(characteristic) << std::endl;
            for (auto& descriptor : characteristic.descriptors()) {
                std::cout << "    Descriptor " << descriptor.uuid() << std::endl;
            }
        }
    }

    peripheral.disconnect();
    std::cout << "Disconnected" << std::endl;
    return 0;
}
```

```c
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <simplecble/simplecble.h>

static const simpleble_uuid_t SERVICE = {"76a60001-a8e9-4660-bc7b-ed8d93a6849e"};

static bool advertises_service(simpleble_peripheral_t device, simpleble_error_t** error) {
    bool found = false;
    simpleble_service_list_t services = NULL;
    size_t count = simpleble_peripheral_services(device, &services, error);
    for (size_t i = 0; i < count && !found && !*error; i++) {
        simpleble_service_t service = {0};
        simpleble_service_list_get(services, i, &service, error);
        found = !*error && strcmp(service.uuid.value, SERVICE.value) == 0;
        simpleble_service_release(&service);
    }
    simpleble_service_list_release(services);
    return found;
}

// Returns an owned handle to the first device that advertises the course service, or NULL.
static simpleble_peripheral_t find_course_peripheral(simpleble_adapter_t adapter, simpleble_error_t** error) {
    simpleble_peripheral_t peripheral = NULL;
    simpleble_peripheral_list_t results = NULL;
    size_t count = 0;
    simpleble_adapter_scan_for(adapter, 5000, error);
    if (!*error) count = simpleble_adapter_scan_get_results(adapter, &results, error);

    for (size_t i = 0; i < count && !peripheral && !*error; i++) {
        simpleble_peripheral_t device = simpleble_peripheral_list_get(results, i, error);
        if (!*error && advertises_service(device, error)) {
            peripheral = device;
        } else {
            simpleble_peripheral_release_handle(device);
        }
    }
    simpleble_peripheral_list_release(results);
    return peripheral;
}

static void print_properties(const simpleble_characteristic_t* characteristic) {
    const bool flags[] = {characteristic->can_read, characteristic->can_write_request,
                          characteristic->can_write_command, characteristic->can_notify,
                          characteristic->can_indicate};
    const char* names[] = {"read", "write", "write without response", "notify", "indicate"};
    const char* separator = "";
    for (size_t i = 0; i < sizeof(names) / sizeof(names[0]); i++) {
        if (!flags[i]) continue;
        printf("%s%s", separator, names[i]);
        separator = ", ";
    }
}

static void print_services(simpleble_peripheral_t peripheral, simpleble_error_t** error) {
    simpleble_service_list_t services = NULL;
    size_t count = simpleble_peripheral_services(peripheral, &services, error);
    for (size_t i = 0; i < count && !*error; i++) {
        simpleble_service_t service = {0};
        simpleble_service_list_get(services, i, &service, error);
        if (*error) break;
        printf("Service %s\n", service.uuid.value);
        for (size_t j = 0; j < service.characteristic_count; j++) {
            const simpleble_characteristic_t* characteristic = &service.characteristics[j];
            printf("  Characteristic %s: ", characteristic->uuid.value);
            print_properties(characteristic);
            printf("\n");
            for (size_t k = 0; k < characteristic->descriptor_count; k++) {
                printf("    Descriptor %s\n", characteristic->descriptors[k].uuid.value);
            }
        }
        simpleble_service_release(&service);
    }
    simpleble_service_list_release(services);
}

int main(void) {
    simpleble_error_t* error = NULL;
    simpleble_adapter_list_t adapters = NULL;
    simpleble_adapter_get_adapters(&adapters, &error);
    simpleble_adapter_t adapter = error ? NULL : simpleble_adapter_list_get(adapters, 0, &error);
    simpleble_adapter_list_release(adapters);

    simpleble_peripheral_t peripheral = error ? NULL : find_course_peripheral(adapter, &error);
    if (!error && !peripheral) {
        printf("Course peripheral not found. Start it and run this program again.\n");
        simpleble_adapter_release_handle(adapter);
        return EXIT_FAILURE;
    }

    char* address = error ? NULL : simpleble_peripheral_address(peripheral, &error);
    if (!error) printf("Connecting to %s\n", address);
    simpleble_free(address);

    if (!error) simpleble_peripheral_connect(peripheral, &error);
    if (!error) printf("Connected\n");
    if (!error) print_services(peripheral, &error);
    if (!error) simpleble_peripheral_disconnect(peripheral, &error);
    if (!error) printf("Disconnected\n");

    int result = error ? EXIT_FAILURE : EXIT_SUCCESS;
    if (error) fprintf(stderr, "%s\n", simpleble_error_message(error));
    simpleble_error_release(&error);
    simpleble_peripheral_release_handle(peripheral);
    simpleble_adapter_release_handle(adapter);
    return result;
}
```

```java
import java.util.ArrayList;

import org.simplejavable.Adapter;
import org.simplejavable.Characteristic;
import org.simplejavable.Descriptor;

public class ExploreGatt {
    static final String SERVICE = "76a60001-a8e9-4660-bc7b-ed8d93a6849e";

    static boolean advertisesService(Peripheral device) {
        return device.services().stream().anyMatch(service -> service.uuid().equals(SERVICE));

    static String properties(Characteristic characteristic) {
        List<String> names = new ArrayList<>();
        if (characteristic.canRead()) names.add("read");
        if (characteristic.canWriteRequest()) names.add("write");

        if (characteristic.canNotify()) names.add("notify");

    public static void main(String[] args) throws Exception {

        adapter.scanFor(5000);

            System.out.println("Course peripheral not found. Start it and run this program again.");

            System.out.println("Service " + service.uuid());
            for (Characteristic characteristic : service.characteristics()) {
                System.out.println("  Characteristic " + characteristic.uuid() + ": " + properties(characteristic));
                for (Descriptor descriptor : characteristic.descriptors()) {
                    System.out.println("    Descriptor " + descriptor.uuid());
                }
            }
        }

        peripheral.disconnect();
        System.out.println("Disconnected");
    }
}
```

```kotlin
        Log.d("SimpleBLE", "Service ${service.uuid}")
        for (characteristic in service.characteristics) {
            Log.d("SimpleBLE", "  Characteristic ${characteristic.uuid}: ${properties(characteristic)}")
            for (descriptor in characteristic.descriptors) {
                Log.d("SimpleBLE", "    Descriptor ${descriptor.uuid}")
            }
        }
    }

    peripheral.disconnect()
    Log.d("SimpleBLE", "Disconnected")
}
```

</Tabs>

In React Native and Android, call `exploreGatt` from your app once it holds the Bluetooth permissions, including the one to connect. [Permissions](/fundamentals/permissions) lists them for each platform.

## What you should see

A line for every service, characteristic and descriptor, with the properties of each characteristic:

```
Connecting to 7C:2E:0D:A4:58:13
Connected
Service 0000180a-0000-1000-8000-00805f9b34fb
  Characteristic 00002a50-0000-1000-8000-00805f9b34fb: read
Service 76a60001-a8e9-4660-bc7b-ed8d93a6849e
  Characteristic 76a60002-a8e9-4660-bc7b-ed8d93a6849e: read, write, write without response
  Characteristic 76a60003-a8e9-4660-bc7b-ed8d93a6849e: read, notify, indicate
    Descriptor 00002902-0000-1000-8000-00805f9b34fb
Disconnected
```

Message allows read, write and write without response, and Counter allows read, notify and indicate, as the course peripheral defines them. Device Information, `0x180A`, and its PnP ID characteristic, `0x2A50`, come from the operating system on the peripheral side, which can add other standard services too.

Counter has one descriptor, the CCCD, `0x2902`. The course peripheral never defined it. The system adds a CCCD to every characteristic that notifies or indicates, because that is where each central's subscription lives. Message neither notifies nor indicates, so it has no descriptors.

## Exercise

Look up every UUID your program printed in the GATT UUID Lookup, starting with the standard ones, such as `0x180A`, `0x2A50` and `0x2902`. Note which come from the Bluetooth SIG and which are the course's own. The lookup names each standard UUID as a Bluetooth SIG service, characteristic or descriptor. The course's UUIDs show as custom 128-bit UUIDs, because they belong to the course alone.

If you own another device that accepts connections, such as a fitness band or a sensor, explore it too. Change the helper so it matches the device's name, the identifier you printed in [Scan for BLE Devices](/learn/scan-for-ble-devices), instead of the course service. Run the program and look up the UUIDs it prints. Most devices show standard services, such as Battery Service, `0x180F`, next to their maker's own 128-bit services.

## Troubleshooting

- **The program prints `Course peripheral not found`.** Start the course peripheral as in [Connect to a BLE Device](/learn/connect-to-a-ble-device#start-the-course-peripheral). It advertises for 10 minutes and then stops, so start it again if it has been running longer.
- **You see more services than the course peripheral defines.** The operating system on the peripheral side adds standard services of its own. That is normal, and the course service is among them.
- **A characteristic has no descriptors.** That is normal for a characteristic that neither notifies nor indicates, such as Message. Descriptors other than the CCCD are optional, and many characteristics have none.
