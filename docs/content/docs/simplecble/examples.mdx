You can find the official examples in the `examples/simplecble` directory of the repository.

- [Scan](https://github.com/simpleble/simpleble/blob/main/examples/simplecble/src/scan.c): Scans for peripherals and prints their details.
- [Connect](https://github.com/simpleble/simpleble/blob/main/examples/simplecble/src/connect.c): Connects to a selected peripheral and lists its services.
- [Notify](https://github.com/simpleble/simpleble/blob/main/examples/simplecble/src/notify.c): Subscribes to notifications from a characteristic.

## Building Examples

To build the examples:

```bash
cmake -S examples/simplecble -B build_examples
cmake --build build_examples
```

The examples use the refactored error API and release all returned service/manufacturer snapshots. Run the executables from `build_examples/bin`. See the [tutorial](./tutorial) for local hosting and backend selection, and the [migration guide](./migration) to update an existing application.
